# Herdr plugins in muxr

muxr runs Herdr plugins through **Applications**. Plugin code runs on your computer.

Browse [herdr.dev/plugins](https://herdr.dev/plugins/) and follow a plugin’s installation instructions to install it in Herdr. Enabled plugins with global actions appear under **Applications** in muxr. Open Applications on your phone and choose an action to run it.

Herdr manages plugin installation, configuration, and logs. To build your own, read the [Herdr plugin guide](https://herdr.dev/docs/plugins/).
