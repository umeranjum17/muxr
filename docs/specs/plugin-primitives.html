Plugins on primitives

tested

plugin-primitives.md · created 2026-08-15 · updated 2026-08-18 · umer

Primitives, slots, actions, capabilities, and runtime contracts are the public platform. Inbox, Voice, Preview, Changes, Attachments, and future product features are plugins composed entirely from it.

Decision

Enabled Herdr plugins remain trusted and default-on. Enabling or linking is the user's trust decision. Explicit disable and revoke remain authoritative. This rework strengthens the platform without adding per-device hash reapproval.

Five platform layers

  1. Kernel: pairing, E2EE, relay, terminal, secure storage, OS bridges, file handoff, realtime transports, and unconditional Android foreground-service ownership.
  2. Targets and slots: typed context, cardinality, ordering, allowed primitives, and failure behavior.
  3. Primitives: reusable native components with validated parameters and result schemas, never renamed product features.
  4. Actions, events, and capabilities: host-mediated navigation, refresh, copy, URL/file handoff, composer input, notifications, RPC, and OS effects.
  5. Plugins: one public package contract for bundled and third-party features, with no private route, renderer, or capability.

Execution

  1. Validate primitive slots, required context, and bounded per-primitive parameters.
  2. Dispatch only closed, bounded actions from generic rows, buttons, settings, and RPC item lists.
  3. Keep foreground keepalive and preview transport in the kernel. Voice, Inbox, Workspace, Dictation, and Run Server own generic controls/content and closed actions.
  4. Hard-kill stuck RPCs, isolate concurrency, and stop repeated full catalog reparsing.
  5. Publish schemas and prove bundled plus adversarial third-party plugins on Android.

Latest revision

Browser grants admit only explicitly read-mode RPCs from package-owned bundled plugin roots. Omitted modes and third-party self-declarations fail closed, while read-only session opens leave global attention untouched. Terminal links are stripped statefully, reject control, bidi, and credential-bearing forms, canonicalize through the platform URL parser, and remain latest-first and bounded across sessions.
