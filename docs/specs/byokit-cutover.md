# Byokit link-only cutover inventory

This is a one-shot wire break. Older phone builds and pre-cutover computer/phone pairings must update and pair again. No muxr relay socket, ticket, envelope, or fallback is retained. Product request/response and event types remain transport-neutral; Noise IK, streams, routing and trust live in infrastructure adapters. Hosted muxr-cloud mode is retired; only owner-operated self-host and shared self-hosted relay enrollment remain. App Review needs a self-hosted sandbox path before release.

## Byokit gaps (direct dependency removal)

- `@byokit/reach@0.2.0` now supplies React Native `browse`/`scan` with explicit preemption. Nearby relay and SSH discovery use it; muxr's direct `react-native-zeroconf` dependency is removed, while reach pins the native companion transitively. A rebuilt native binary is required; device discovery QA remains outside this no-physical-phone lane. `bonjour-service` stays transitively owned by reach.
- `@byokit/seal@0.1.0` now owns mobile catalog/account/blob encryption without changing stored bytes. `tweetnacl` remains for peer/setup signatures and legacy transport until those consumers are removed. Root `libsodium-wrappers` remains in old diagnostics, and the `naclPRNG` entry import still needs an import inventory before deletion.
- `@byokit/relay` already owns link push and its Web Push/Expo transports; muxr's old `PushService` and direct `web-push` dependency are gone. Voice-provider WebSockets still need custom handshake headers and HTTP rejection bodies (`openai.mjs`, `gemini.mjs`, `xai.mjs`), so direct `ws` stays for those adapters. Peer product requests now use a byokit device link; legacy peer authority and relay routing still need deletion.

- On a shared relay, `muxr pair` asks the already-enrolled running machine link to open an offer through the owner-only local pairing socket; it does not mint a second relay host or use an old relay credential. If muxr is stopped, start it before pairing. On an owned relay only, the CLI may start an ephemeral pairing host when no machine host is available.

## Deletion gate

Do not delete a fallback that an unmerged step lane still depends on. Rebase this branch after terminal, desktop, voice, pairing and step-5 PRs merge, then remove their old arms in the same candidate. Qualify a real relay and host for terminal, desktop signaling, voice, pairing, push and reconnect; run typecheck and the full suite. Physical-phone QA belongs to the separate pre-release pass.
