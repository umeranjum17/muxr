# Agent marks

The README uses self-contained light and dark grids selected by GitHub's
`#gh-light-mode-only` and `#gh-dark-mode-only` fragments. Both embed the same 22
transparent, normalized monochrome marks as the mobile app; only their neutral
foreground differs. Geometry sources and source categories are recorded in
[`apps/mobile/sources/assets/agents/ATTRIBUTION.md`](../../../apps/mobile/sources/assets/agents/ATTRIBUTION.md).

The former Pi and OMP badge SVGs were retired: their opaque backing tiles and
special-case sizing were inconsistent with the complete mark system.
