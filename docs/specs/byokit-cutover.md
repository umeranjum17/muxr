# Byokit link-only cutover inventory

This is a one-shot wire break. Older phone builds and pre-cutover computer/phone pairings must update and pair again. No muxr relay socket, ticket, envelope, or fallback is retained. Product request/response and event types remain transport-neutral; Noise IK, streams, routing and trust live in infrastructure adapters.

## Byokit gaps (direct dependency removal)

- `@byokit/reach` needs a React Native mDNS **browse** API (start/stop discovery, service addresses/port/TXT, error lifecycle) for `useRelayDiscovery.ts` and `SshHostScan.tsx`. It currently exports Node `advertise` and route/Serve selection only; removing `react-native-zeroconf` before this API lands would remove LAN discovery and SSH host scanning. `bonjour-service` is transitively owned by `@byokit/reach`, not a muxr direct dependency.
- Byokit needs a cross-platform crypto API for the surviving stored catalog/account payloads: key-seeded X25519 box seal/open, XSalsa20-Poly1305 secretbox seal/open in the existing byte format, and Ed25519 sign/verify for peer descriptors and setup grants. `@byokit/link` currently exports Noise link key pairs and secure grant stores, not these application-at-rest/signature operations. This blocks deleting `tweetnacl`, `libsodium-wrappers`, `@more-tech/react-native-libsodium`, its type package and `naclPRNG` until old transport-only callers are deleted and the remaining data can use the byokit API without data loss.
- `@byokit/relay` already owns link push and its Web Push/Expo transports; `web-push` remains only in muxr's old `PushService` and can go when that service and its old persistence tests are deleted. Voice-provider WebSockets still need custom handshake headers and HTTP rejection bodies (`openai.mjs`, `gemini.mjs`, `xai.mjs`), so direct `ws` stays for those adapters until a platform replacement preserves both; product relay/preview/plugin/peer sockets must move to byokit streams.

- On a shared relay, `muxr pair` asks the already-enrolled running machine link to open an offer through the owner-only local pairing socket; it does not mint a second relay host or use an old relay credential. If muxr is stopped, start it before pairing. On an owned relay only, the CLI may start an ephemeral pairing host when no machine host is available.

## Deletion gate

Do not delete a fallback that an unmerged step lane still depends on. Rebase this branch after terminal, desktop, voice, pairing and step-5 PRs merge, then remove their old arms in the same candidate. Qualify a real relay and host for terminal, desktop signaling, voice, pairing, push and reconnect; run typecheck and the full suite. Physical-phone QA belongs to the separate pre-release pass.
