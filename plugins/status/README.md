# Status

Coding-agent usage and machine vitals.

- **Activity:** pinned ccusage 20.0.20 loads `daily --by-agent --sections daily,session --json --offline`. The screen shows seven local calendar days, including idle days. OpenCode activity already includes its SQLite store; no separate token counter is used for Go.
- **OMP:** reads aggregate token/cost columns from its local `stats.db` in a read-only, time-bounded child. Respects OMP/PI profile, PI_CONFIG_DIR and existing XDG data roots. Uses Node's SQLite reader or Python 3's standard library on older Node 22 installations; if neither is available, the screen names the missing runtime. It never launches OMP or Pi.
- **Plan limits:** Claude uses its fresh local status-line snapshot or Anthropic account endpoint; Codex uses its app-server and includes both primary and secondary windows. OpenCode Go uses the first-party `https://opencode.ai/zen/go/v1/usage` endpoint for rolling, weekly and monthly utilization. Only `opencode-go` API credentials are selected: valid `OPENCODE_AUTH_CONTENT` takes precedence over `$XDG_DATA_HOME/opencode/auth.json` (default `~/.local/share/opencode/auth.json`). Credentials never enter output or the output cache. Other providers explicitly show unsupported plan limits; failed reads show unavailable, not zero.
- **Host boundary:** provider paths/profiles and auth-content overrides travel on private stdin only to the canonical bundled Usage implementation. Generic plugin environments stay closed; third-party plugins cannot receive these settings by claiming the Status id.
- **Recency:** tabs sort by recorded consumption timestamps, independent of token volume. ccusage supplies session `metadata.lastActivity` across its available history; OMP's stats and OpenCode's message database provide last consumption beyond that window. Providers without a known timestamp sort alphabetically after known ones. No file modification times are treated as usage.
- **Bounds:** ccusage 10s, Codex 8s, local SQLite helper 5s, and selected Claude/Go request 5s. Backend aggregate reports may be up to 8 MiB; the displayed model contains only bounded provider/model labels, estimated costs, tokens, and quota windows. Prompts, project details and session identifiers stay out. Owner-only per-tab caches expire after one minute (Claude 15s); failed activity/limit reads are not cached. A secret-free configuration/account fingerprint invalidates the same cache entry when profiles, locations, overrides or the active Go key change.
- **Vitals:** disk, memory, load, and uptime of the machine running your agents.
- **Removal:** `herdr plugin unlink muxr.status`.
