# Store review fixture

The reviewer fixture runs on the **dedicated** `review.trymuxr.com` machine, not the server hosting `trymuxr.com`. The old `review.178.104.81.27.sslip.io` Coolify application was removed. The host and relay use the published muxr **0.2.1** CLI; the phone must use the matching native release candidate. Do not put invitation tokens, reviewer grants, or signing material in this repository.

- `reviewer` owns muxr's private state and `/demo-shop`. Its user-systemd `herdr.service` and `muxr.service` run Herdr and `muxr self-host --advertise wss://review-relay.trymuxr.com --port 8892 --no-pair --yes`. Set the machine name to `muxr Review`. Caddy forwards `review.trymuxr.com` to the loopback invitation broker on port 8080 and `review-relay.trymuxr.com` to the loopback relay on port 8892. Leave the existing Caddy video routes in place.
- In Herdr, create a `Review` workspace at `/demo-shop`, rename its single pane `Review agent`, and run `review-agent.sh` there **without** claiming an agent lifecycle/session. It is an intentionally limited synthetic shell, not a real model. The existing daily `muxr-review-reset.timer` resets `/demo-shop` to `review-baseline` and seeds its harmless demo diff. Keep the pane and its terminal available across resets.
- Install `invite.mjs` as the unprivileged `muxr-review-invite.service`. Its environment must supply `REVIEW_INVITE_TOKEN_HASH` (SHA-256 of a freshly minted 32-byte random token), `REVIEW_INVITE_EXPIRES_AT`, `REVIEW_INVITE_MAX_CLAIMS`, `MUXR_BIN` and `PORT=8080`. Store the token only in owner-readable private storage; the workstation's durable `https://review.trymuxr.com/invite/<token>` belongs in `~/.config/muxr/review-invite.url` at mode 600. Rotate it if exposed. Each visit mints a short-lived, single-use pairing link; the broker approves only the disposable review computer's pairing request while the phone still asks the reviewer to confirm.

Verify the public `/health`, the HTTPS relay, and a fresh invitation from outside the VM. On the exact native candidate, pair using the invitation, open **Review → Review agent**, send `Create review.txt containing hello`, and open **Changes → review.txt**. Check the actual file in `/demo-shop`, a restart/reconnect, the daily reset timer, and that `trymuxr.com` remains untouched. A server with no desktop cannot demonstrate desktop sharing; optional voice needs a configured provider. The synthetic pane is intentionally shown as a shell, so do not claim a live model agent in review notes.
