# Agent marks

The PNGs in this directory are transparent monochrome masks derived from the
listed upstream geometry, then optically normalized to a shared 256×256 canvas.
Normalization changes color, scale, and padding only; it does not redraw marks.
Product and brand assets remain subject to their owners' trademark terms.
