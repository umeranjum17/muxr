# Workspace Hierarchy

Transforms the host's bounded public `workspace-tree` context into generic `tree-sheet` nodes. The renderer presents titles/status/current state and dispatches validated session navigation; it no longer owns herdr RPCs, layout storage, split policy, or feature routes.

- **Host:** `rpc.mjs tree` receives the current muxr session id as input and `MUXR_PLUGIN_CONTEXT_JSON` because the manifest declares `context: ["workspace-tree"]`.
- **Close:** `rpc.mjs close` is the packaged `muxr.workspace-hierarchy` implementation of the reserved `agent.close` capability (`agent.close` → contribution `close` → method `close`, write mode). The host pins that identity and packaged root, so disabling its optional UI does not remove kernel Agent close and a third-party `close` method cannot claim it. RPC input is only `{ paneId, confirmedScope? }`; a non-default Herdr socket is private child transport context in `MUXR_HERDR_SOCKET_PATH`, never RPC input or output. The RPC inspects a live Herdr `session.snapshot` and calls only the `pane.close` / `tab.close` / `workspace.close` allowed by the confirmed scope. Muxr does not infer that scope from cached pane/tab/workspace counts. Broader closes stay confirmation-gated (`tab` → `workspace` → `worktreeGroup`); cancel is no request. If Herdr refuses because topology widened after the snapshot, the plugin revalidates and asks strictly beyond both the attempted and already-confirmed scopes. A revalidation outage returns Retry, never already closed.
- **Current cut:** New tab, split, tab grid, save/restore layout, watch/focus actions are omitted until they fit declared write RPCs without exposing internal pane/tab/workspace ids.
- **Removal:** `herdr plugin unlink muxr.workspace-hierarchy`
