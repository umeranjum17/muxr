# ASO screenshots

The store sets combine clean muxr component renders with one background generated by **Codex GPT Image 2** from the real Herd capture and a visual reference. Codex supplies the atmospheric campaign field; the real UI is composited back pixel-for-pixel so the model cannot rewrite product text or controls.

```bash
cd tools/demo
npm run aso
```

Outputs:

- Google Play phone: `docs/play/store-assets/aso/` — 1080×1920, frameless UI
- App Store iPhone 6.9-inch: `docs/app-store/screenshots/` — 1320×2868, unframed UI
- App Store iPad 13-inch: `docs/app-store/screenshots-ipad/` — 2064×2752, dedicated split view

`validate.mjs` fails on wrong dimensions, transparency, non-sRGB output, Play aspect violations, or missing assets.

## Review safety

- muxr declares `supportsTablet: true`, so the iPad set is separate rather than stretched phone artwork.
- No unofficial Apple device bezel, Android/Play branding, price, ranking, award, URL, or install CTA appears in Apple assets.
- Play assets contain no device frame and keep headline copy within the top fifth.
- Every visible feature exists in the reviewed app: Herd, Inbox attention, terminal approval, Changes, Realtime voice, and self-hosted relay.
- All assets are opaque PNGs using accepted exact dimensions.
