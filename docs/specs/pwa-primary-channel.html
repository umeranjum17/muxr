muxr is acquired demo-first from trymuxr.com, installed Herdr-first from its exact GitHub source, set up through one inspect → plan → apply flow, and used daily as a PWA served from the user's own HTTPS host origin. Native apps are optional upgrades. The full frozen contract text is the Markdown source; this page is the reading view.

Product order

  1. Visitor opens trymuxr.com and tries a credential-free demo.
  2. Chooses Connect your computer: Herdr plugin from exact GitHub source, npm/CLI only as fallback.
  3. Setup recommends one browser-capable HTTPS route, shows one inspectable plan, applies it.
  4. User opens muxr from their host origin, optionally installs the PWA, consents to a scoped browser grant.
  5. Performs one useful action against a real Herdr session.
  6. Notifications, voice, extensions, advanced networking and native apps only when relevant.

Invariants

  • E2EE mandatory for every payload class; relay never sees plaintext or credentials.
  • Browser authority is explicit by role and expiry; installed display mode grants nothing extra.
  • Revocation closes sockets, invalidates tickets, rotates keys.
  • Preview content never gains trusted-origin storage, opener, top navigation or cookies.
  • One takeover controller at a time; provider policy and credentials stay host-owned.
  • Secret-bearing values are never echoed in logs, receipts, screenshots or errors.
  • Drafts, attachments, wrapping keys, grants and pending commands survive concurrency without silent loss or duplication.

Blockers to close

  • S1 Config secret echo: reject userinfo/query/fragment; errors name key and rule, never the value.
  • S2 Browser wrapping-key race: atomic IndexedDB creation across tabs/realms.
  • S3 Preview top-level isolation enforced at the service-worker/bridge boundary.
  • S4 Herdr runtime update record refreshed atomically; failed update preserves the prior runtime.
  • S5 Integrate current main first; candidate gates identify exact package/plugin/export/SHA tuple.
  • S6 Browser-first route; no silent native demotion; Safari tab pairing with explicit install-partition note.
  • S7 Provider-neutral clients; provider selection and secrets are host/plugin operations.

Herdr plugin path

herdr plugin install umeranjum17/muxr/plugins/control --ref <released-ref>
herdr plugin pane open --plugin muxr.control --entrypoint setup

Build resolves npm latest to one exact verified version; runtime state stays under ~/.muxr; startup hook is one-shot; default Pair is browser Control; uninstall is bounded.

Verification

  • Clean pushed branch integrating current main with no dependency/version downgrade.
  • Fake-secret canaries absent from text and JSON; concurrent wrapping keys reload; top-level preview authority fails; plugin update/rollback keeps an operable runtime.
  • Clean Herdr journey through a disposable registry with exact identities and no local links.
  • TUI and JSON plans agree; second apply is a no-op; failures never print Complete.
  • Demo → Herdr → setup → host PWA → pair → first action; docs/link/command gates.
  • Full diagnostics suite once against one immutable candidate tuple.
