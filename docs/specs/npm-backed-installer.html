npm-backed-installer.md · created 2026-08-20 · updated 2026-08-20 · umer

npm stays canonical. The shell installer is a small, reviewable convenience wrapper, not a second runtime or package manager.

Problem

Users expect a downloadable installer, while muxr already has a correct Node/npm release and update path. Bundling Node or inventing another distribution would split ownership and make upgrades ambiguous.

Decision

  • Require Node 22+ and npm.
  • Run npm install --global --ignore-scripts @trymuxr/cli.
  • Never use sudo or install Node.
  • Validate the exact binary under npm's active global prefix.
  • Download fully to mktemp before execution.
  • Serve the canonical root script through GitHub raw and copy it into packaged/deployed web exports.

Updater parity

muxr update also disables lifecycle scripts and refuses npm-prefix drift. It cannot silently install into a different Node-version-manager environment from the running package.

Verification

  • POSIX syntax check passes
  • Fake Node/npm flow covers whitespace prefix, stale PATH, old Node, injection, and permission failure
  • Real isolated install of published 0.1.11 succeeds
  • Workspace build and full package smoke pass
  • Packaged web artifact includes the canonical installer
  • Independent security review findings repaired

Rollback

Remove the convenience URL and root script. npm installation remains fully supported; retain updater prefix and lifecycle-script hardening.
