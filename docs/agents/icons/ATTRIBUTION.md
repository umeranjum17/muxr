# Agent icons

Only verified upstream marks remain:

- `pi.svg` is the adaptive mark from [pi.dev](https://pi.dev/logo-auto.svg)
  (MIT); `pi-badge.svg` places its unchanged black light-mode mark on a white
  square background for deterministic README visibility.
- `omp.svg` is the unchanged upstream mark from
  [Oh My Pi](https://github.com/can1357/oh-my-pi/blob/main/assets/icon.svg)
  (MIT).
- `omp-badge.svg` centers that unchanged 4:3 OMP mark on a dark square
  background for visibility on light and dark README surfaces.

Other agent kinds are names in the README and accessible text initials in the
app; they do not use invented or recolored logo assets.
